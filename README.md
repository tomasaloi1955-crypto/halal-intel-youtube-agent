# Халяль Интеллидженс — YouTube Agent

Автоматический агент: тема → сценарий → озвучка → видео → YouTube.

## Формат Shorts

Каждый ролик — 25-30 секунд, и содержание лежит **в кадре**, а не в стоковом видеоряде:
сам промпт, сам шаг, сама цифра. Кадры сменяются в такт голосу — тайминги берутся из
посимвольной разметки ElevenLabs (`/with-timestamps`).

Кадр собирается двумя слоями:

- **снизу** — тематическое фото с Pexels, размытое и медленно плывущее; на каждую сцену
  своё, поэтому визуал меняется по ходу ролика. Запросы для фона (`bg_queries`) даёт
  та же нейросеть, что пишет сценарий, первый всегда про экран/компьютер;
- **сверху** — накладка с текстом, она не масштабируется и остаётся резкой.

Фото уходит под полупрозрачную вуаль (`shorts_frames._make_scrim`), которая гуще у
верхнего и нижнего края — там бейджи и плашка Telegram. Промпт в рубрике «Промпт дня»
**печатается на экране**: окно чата с заголовком, кнопками и мигающей кареткой, текст
набирается по символам (`video_maker._typing_subframes`), затем висит целиком — его
переписывают с экрана. Нет ключа Pexels или сеть не ответила — кадры рисуются на
сплошном фирменном фоне, ролик всё равно собирается.

- `shorts_frames.py` — рисует фирменные кадры 720×1280 (Pillow)
- `shorts_timing.py` — раскладывает кадры по времени под озвучку
- `ai_shorts.py` — сценарии рубрик (нейросеть заполняет структуру, а не пишет полотно)
- `video_maker.make_brand_shorts()` — сборка ролика из кадров

У роликов сквозная нумерация (`#48` в углу) — она делает из выпусков сериал.
Счётчик живёт в `state/shorts_episode.json`.

## Расписание

| День | Рубрика | Что зритель уносит |
|------|---------|--------------------|
| Пн | Промпт дня | Готовый промпт, который копируют с экрана |
| Вт | ИИ за 20 секунд | Фишка инструмента в три шага |
| Ср | Промпт дня | — |
| Чт | ИИ за 20 секунд | — |
| Пт | Промпт дня | — |
| Сб | Халяль или харам? | Вердикт + выбор А/Б в комментарии |
| Вс | Вау-новость | Одна цифра недели и что она меняет |

Темы рубрик «Промпт дня» и «ИИ за 20 секунд» берутся из `topic_bank.py`: сначала
базовый список, потом Gemini дописывает новые. Курсор двигается на каждом выпуске
(`state/bank_prompts.json`, `state/bank_tricks.json`), а не раз в неделю — иначе
рубрика, выходящая трижды в неделю, повторяла бы одну и ту же тему.

## Темы уроков по автоматизации (старый формат, не в расписании)

- Недели 1-16: 16 готовых тем (халяль бизнесы из СНГ и мира)
- Неделя 17+: агент сам исследует интернет через Gemini, находит новые бизнесы
- Харам-фильтр: банки, ломбарды, алкоголь, свинина, сигареты, казино — исключены автоматически
- Повторы исключены: агент запоминает все использованные бизнесы в used_topics.json

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Заполни .env своими ключами
```

## Ключи API

| Сервис | Где получить | Стоимость |
|--------|-------------|-----------|
| Gemini | aistudio.google.com | Бесплатно |
| Pexels | pexels.com/api | Бесплатно |
| ElevenLabs | elevenlabs.io | $5/мес |
| YouTube | console.cloud.google.com | Бесплатно |

## YouTube OAuth (один раз)

1. console.cloud.google.com → новый проект
2. APIs → Enable → YouTube Data API v3
3. Credentials → OAuth 2.0 Client ID → Desktop App → скачай JSON
4. Переименуй в youtube_credentials.json
5. python main.py --once → браузер → авторизуйся

## Запуск

```bash
python main.py --once          # тест один раз
python main.py --digest        # принудительно дайджест
python main.py --automation    # принудительно урок
python topic_researcher.py --prefetch  # заранее заготовить 10 тем
python main.py                 # полный режим с расписанием
```

## Деплой на Render.com

1. Загрузи на GitHub (без .env и youtube_credentials.json)
2. Render → New Web Service → подключи репо
3. Build: pip install -r requirements.txt
4. Start: python main.py
5. Environment Variables: добавь все из .env
6. Secret Files: добавь youtube_credentials.json
