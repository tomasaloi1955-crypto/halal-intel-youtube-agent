# Агент рекламы в Meta (Facebook / Instagram)

`meta_ads_agent.py` ведёт четыре кампании через Meta Marketing API:

| Ключ | Кампания |
|------|----------|
| `fitness20` | Женские тренировки 20 минут — пилатес и аэробика (t.me/ilikeislamandsport) |
| `tajweed` | Таджвид, разговорный арабский, хифз (t.me/myarabicl) |
| `tamra` | Онлайн-школа «Тамра» для детей (t.me/tamra_school) |
| `automation` | Автоматизация бизнес-процессов и AI-агенты (t.me/Halalaifreya) |

Все настройки лежат в `meta_ads/campaigns.json`: бриф, ссылка, картинка, цель, целевая цена
результата, возраст, интересы, готовые тексты на случай, если Claude недоступен.

## Что делает агент

1. **`setup`** — для каждой кампании создаёт кампанию → группу объявлений → 3 объявления.
   Тексты пишет Claude (`meta_ads/copywriter.py`) по брифу и правилам Meta. Всё создаётся
   **на паузе**.
2. **`activate`** — включает кампании. Сначала проверь их в Ads Manager.
3. **`optimize`** — каждый день в 10:00 по Алматы (GitHub Actions):
   - перераспределяет общий дневной бюджет между кампаниями (см. ниже);
   - ставит на паузу объявления с CTR ниже 0.4% на 2000+ показах или с ценой результата
     больше 2.5× цели (последнее активное объявление группы не трогает);
   - когда частота выше 3.5 или активных объявлений меньше двух, просит у Claude новый
     текст с учётом статистики прошлых и запускает его;
   - присылает отчёт в Telegram.
4. **`report`** — тот же отчёт, без изменений.

## Таргетинг: СНГ

По умолчанию: Казахстан, Узбекистан, Кыргызстан, Таджикистан, Азербайджан, Армения,
Беларусь, Молдова. Язык интерфейса — русский. Кампания `automation` идёт на свой список стран,
женские тренировки показываются только женщинам, «Тамра» — родителям 25–55 лет.

- **Россию в список не включай.** С 2022 года Meta не показывает рекламу пользователям в
  России. Агент сам убирает RU и TM из списка и пишет об этом в лог.
- Интересы и языки задаются названиями. Агент находит их id через `/search` и кэширует.
  Интерес, который Meta удалила (например, религиозные), агент пропускает с предупреждением.
- По политике Meta о личных характеристиках текст объявления не может утверждать религию,
  здоровье или вес читателя. Это правило зашито в промпт копирайтера, особенно для таджвида
  и фитнеса.

## Динамический бюджет

Бюджет задаётся на уровне кампании (Advantage campaign budget), и агент двигает только его
(`meta_ads/budget.py`):

- цена результата (CPA) считается за 7 дней, причём свежие дни весят больше;
- CPA сглаживается к цели: пока данных мало, бюджет почти не двигается;
- деньги идут туда, где результат дешевле цели, но **не больше ±20% в день**: резкие
  изменения у Meta перезапускают обучение;
- кампанию в фазе обучения (первые 3 дня, а также пока группа в статусе LEARNING, но не
  дольше недели) агент не трогает;
- кампании, которая и текущий бюджет не тратит, бюджет не растёт;
- на каждую кампанию приходится от `min_daily_budget` до `max_daily_budget`, а сумма никогда
  не превышает `total_daily_budget`.

## Настройка

1. Business Manager → **System User** → токен с правами `ads_management`, `ads_read`,
   `pages_read_engagement`, `pages_show_list`. Добавь пользователю доступ к рекламному
   аккаунту и к странице.
2. GitHub Secrets: `META_ACCESS_TOKEN`, `META_AD_ACCOUNT_ID` (`act_…`), `META_PAGE_ID`,
   по желанию `META_IG_USER_ID`, `META_PIXEL_ID`, а также `ANTHROPIC_API_KEY`.
3. В `meta_ads/campaigns.json` укажи для каждой кампании `image` — путь к картинке 1080×1080
   в репозитории. Ссылки на Telegram-каналы и описания уже заполнены.
4. Запусти workflow **meta_ads** вручную с командой `setup`. Пока переменная репозитория
   `META_ADS_LIVE` не равна `true`, это dry-run: в логе видно, что агент создал бы.
5. Поставь переменную репозитория `META_ADS_LIVE=true`, снова запусти `setup`, проверь
   кампании в Ads Manager, затем запусти `activate`.

Локально то же самое: `python meta_ads_agent.py setup|activate|optimize|report [ключи…]`.

### Telegram-ссылки и цель кампании

Все четыре кампании ведут в Telegram-каналы (`t.me/...`). На t.me нельзя поставить пиксель
Meta, поэтому оптимизация идёт на **клики по ссылке** (`OUTCOME_TRAFFIC` / `LINK_CLICKS`,
результат — `link_click`). Цель «просмотры посадочной страницы» здесь дала бы ноль
результатов. `target_cpa` — это цена клика.

Meta не видит, кто подписался на канал. Чтобы понимать реальную цену подписчика,
сравнивай расход кампании с приростом подписчиков канала.

Когда появится свой сайт с пикселем, кампанию можно перевести на заявки:

```json
"link": "https://твой-сайт/...",
"objective": "OUTCOME_LEADS",
"optimization_goal": "OFFSITE_CONVERSIONS",
"custom_event_type": "LEAD",
"result_action": "offsite_conversion.fb_pixel_lead"
```

Цель уже созданной кампании Meta поменять не даёт. Удали её ключ из
`state/meta_ads_state.json` и снова запусти `setup`.

## Файлы

- `meta_ads/api.py` — клиент Graph API: повторы при лимитах, пагинация, dry-run
- `meta_ads/targeting.py` — страны СНГ, поиск языков и интересов
- `meta_ads/budget.py` — распределение бюджета и решения по объявлениям
- `meta_ads/copywriter.py` — тексты объявлений через Claude
- `meta_ads/agent.py` — команды setup / activate / optimize / report
- `state/meta_ads_state.json` — id созданных объектов и история бюджетов
- `tests/test_meta_ads_budget.py` — `python -m unittest discover tests`
